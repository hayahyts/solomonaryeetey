# Madhu – Product Designer Portfolio

Next.js 14 + Tailwind CSS + TypeScript + Framer Motion.

## Setup

```bash
npm i
npm run dev
```

## Build

```bash
npm run build && npm run start
```

## Tech
- Next.js App Router
- Tailwind CSS with fluid typography
- Framer Motion animations
- Lucide icons (optional)

## Notes
- Update images and copy inside `components/sections/*`.
- Colors and fonts live in `tailwind.config.ts` and `app/globals.css`.
